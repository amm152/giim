# عالم المعرفة — مدينة المهن 3D (نسخة تجريبية)

افتح `index.html` في Chrome أو Edge مع اتصال بالإنترنت لتحميل Three.js. تجول باستخدام الأسهم أو WASD، واسحب بالماوس لتدوير الكاميرا. اقترب من مبنى واضغط E أو «دخول المبنى الأقرب» للانتقال إلى `missions.html` (اللعبة المهنية السابقة).

## النشر
ارفع الملفات `index.html` و`missions.html` معًا إلى جذر مستودع GitHub، ثم فعّل GitHub Pages من Settings → Pages → Deploy from a branch → main → /(root).

## ملاحظات
هذه **نسخة أولية لعالم 3D** وليست لعبة عالم مفتوح مكتملة بكل الأنشطة داخل المباني. المباني تؤدي إلى ملف المهمات السابق. العرض ثلاثي الأبعاد يتطلب الإنترنت؛ باقي ملف المهمات مستقل. لم يتم إجراء اختبار شامل في متصفحات وأجهزة متعددة.
